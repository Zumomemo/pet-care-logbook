# 🐾 Pet Care Logbook (สมุดบันทึกสัตว์เลี้ยงสุดน่ารัก)

เว็บแอปพลิเคชันสำหรับเจ้าของสัตว์เลี้ยงเพื่อใช้บันทึกประวัติ สุขภาพ วันเกิด โรคประจำตัว อาการแพ้อาหาร ตารางหมอนัด ประวัติการรับวัคซีน และไดอารี่ความทรงจำประจำวันพร้อมอัปโหลดรูปภาพ

---

## 🛠️ Tech Stack & Requirements

* **Language/Environment:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB (รันผ่าน Local / MongoDB Compass)
* **View Engine:** EJS (Embedded JavaScript)
* **File Uploads:** Multer Middleware

---
